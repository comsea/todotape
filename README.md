# TO·DO·TAPE

Weekly to-do list with a retro 80s mixtape aesthetic, built with **Tauri 2** + **React 18** + **TypeScript**.

## Prerequisites

| Tool | Version | Notes |
|------|---------|-------|
| **Node.js** | 20+ | `node --version` |
| **Rust** (+ Cargo) | 1.77+ | `rustup update stable` |
| **WebView2** | any | Pre-installed on Windows 10/11 (1803+); otherwise install from Microsoft |
| **Visual Studio Build Tools** | 2019/2022 | With "Desktop development with C++" workload |

> **Linux / macOS dev**: replace the Windows prereqs with `webkit2gtk-4.1` (Linux) or Xcode CLI (macOS).

## Quick start (development)

```bash
# 1. Install JS dependencies
npm install

# 2. Launch in dev mode (hot-reload)
npm run tauri dev
```

The app opens in a native window. Changes to `src/` reload instantly.

## Building the Windows installer

```bash
# Add the Windows MSVC target if cross-compiling from Linux:
rustup target add x86_64-pc-windows-msvc

# On Windows (or in a GitHub Actions Windows runner):
npm run tauri build
```

Output files:

| File | Location |
|------|----------|
| MSI installer | `src-tauri/target/release/bundle/msi/TO-DO-TAPE_1.0.0_x64_en-US.msi` |
| Portable EXE  | `src-tauri/target/release/todo-tape.exe` |

## Keyboard shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+N` | New task |
| `Ctrl+1` | Switch to Week view |
| `Ctrl+2` | Switch to Today view |
| `Esc` | Close modal / preferences |
| `↑` / `↓` | Navigate tasks in Today view |
| `Space` | Check/uncheck focused task |

## Features

- **Two views**: Week (7 cassette columns) and Today (zoomed cassette)
- **Tray icon**: app keeps running when window is closed; "Quitter" exits
- **Persistence**: JSON stored in `%APPDATA%\com.todotape.app\todotape.json`
- **Preferences panel** (⚙ button or tray): accent colour, density, daily notification, autostart
- **Daily notification** at configurable time (opt-in, off by default)
- **Windows autostart** option (opt-in)

## Project layout

```
src/                  React app (TSX)
  components/         Shared UI primitives
  views/              WeekView, TodayView, DoneDrawer
  store/              Types, seed data, Tauri-Store persistence
  App.tsx             Root component + keyboard shortcuts
  styles.css          All styles (mirrors prototype 1:1)
src-tauri/            Rust backend
  src/lib.rs          Tray icon, window events, plugin init
  tauri.conf.json     App config, bundle settings
  capabilities/       Permission grants for Tauri 2 plugins
  icons/              App icons (generated from script)
public/fonts/         Self-hosted woff2 (Kalam, VT323, Press Start 2P)
```

## Auto-update (placeholder)

The updater plugin dependency is present but the endpoint is empty.  
To wire it up later, set `plugins.updater.endpoints` in `tauri.conf.json` and add your signing public key generated by `tauri signer generate`.

## Font re-download

If you need to refresh the bundled fonts:

```bash
# Re-run from the repo root:
node scripts/download-fonts.js   # (see scripts/ if added later)
# or manually curl each file from Google Fonts → public/fonts/
```
